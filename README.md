# Prompt Dock Backend

Prompt Dock is a community platform for discovering, creating, saving, sharing, and organizing AI prompts and skills.

The backend is built with FastAPI, SQLAlchemy, SQLite, Pydantic, JWT authentication, password hashing, and pytest.

## Requirements

- Python 3.12 or newer
- uv

## Installation

Clone the repository and enter the project folder:

```bash
git clone https://github.com/andreimagn0/prompt-dock.git
cd prompt-dock
